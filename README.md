# Headless: Penetration Testing and Ethical Hacking

## Descrizione
Questo repository documenta un processo di penetration testing condotto su una macchina HackTheBox vulnerabile by design, [Headless](https://www.hackthebox.com/machines/headless). Il progetto include tutte le fasi principali del penetration testing, dal discovery iniziale fino al mantenimento dell'accesso, utilizzando strumenti e metodologie consolidate.



## Struttura del Progetto
La repository contiene i seguenti documenti:
**Penetration Testing Narrative**
   - Descrizione completa delle procedure e dei tool utilizzati per il penetration testing della macchina.
**Penetration Testing Report**
   - Report delle vulnerabilità individuate e degli interventi di remediation da effettuare.
**Presentazione del progetto**
   - Presentazione LaTeX del progetto in sede d'esame.
